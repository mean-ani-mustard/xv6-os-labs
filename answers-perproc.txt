Virtual address 0 contains the first page of the init user program. It includes program code and initialized data. Its PTE has V, R, X, and U permissions, so user mode can read and execute it, but cannot write to it.
Pages at 0x1000 and 0x3000 are normal user data and stack pages. They have V, R, W, and U permissions, meaning user mode can read and write them. Page 0x2000 is the stack guard page. It is mapped, but U is not set, so user mode cannot access it.
The page at TRAPFRAME (0x3fffffe000) stores the process trapframe. It has V, R, and W permissions, but no U, because it is only used by the kernel and trampoline code. The page at TRAMPOLINE (0x3ffffff000) contains trampoline instructions. It has V, R, and X, but no U.
The entries in the upper page-table levels are not normal memory pages. They point to the next page-table level.
The check srcva + len < srcva is needed because addition can overflow. For example, if srcva is 0xfffffffffffffff0 and len is 0x20, their sum wraps around to 0x10. Without this check, the kernel could incorrectly accept an invalid memory range.
